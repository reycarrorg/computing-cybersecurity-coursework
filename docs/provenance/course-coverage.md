# Course coverage and original-source boundaries

This public repository is the **single curated coursework showcase**, not a byte-for-byte mirror of six standalone source repositories. Their complete Git mirrors and portable bundles were retained privately before any source-repository removal. The original histories are intentionally not imported into this public repository because they include assignment answers, third-party/classroom material, and potentially identifying data.

The other course sections are newly written summaries based on the student's own reports and README descriptions; they are not proof of publication permission for the underlying assignments.

Third-party names are used descriptively. No institution or instructor has endorsed this portfolio. See [Rights and attribution](../../RIGHTS_AND_ATTRIBUTION.md).
