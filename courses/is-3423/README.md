# IS 3423 — Network Security

The University of Texas at San Antonio · Spring 2026 · defensive networking

In an isolated cryptography lab, I worked through encryption and decryption, hashing, HMAC verification, public/private key operations, digital signatures, and a self-signed certificate. The exercise helped me distinguish confidentiality from integrity and authentication, and think about why a VPN design has to combine multiple mechanisms rather than rely on one primitive.

The original report also discussed IPsec/VPN concepts. It was a course exercise and does not establish that I deployed or operated a production VPN. Its PDF contains substantial assignment prompt structure and terminal screenshots with local account labels, so neither the raw report nor its images are reproduced here. The original file and history are preserved in a private local recovery archive.
