# COSC 1336 — Programming Fundamentals

Northwest Vista College · Spring 2025 · C++

This course was my progression from basic console input and output to functions, file handling, arrays, structures, and classes. I built a cumulative menu-driven program across the term, adding calculations and small data-processing features as each module introduced a new concept. Later exercises separated a class into a header and implementation file.

The progression taught me to extend existing code without losing track of earlier behavior. Looking back, the original programs are useful evidence of learning, but they also contain classroom demonstrations, assignment-specific answers, templates, and sample contact details. I have not copied those raw files into this public showcase. The complete original repository and history are retained in a private local recovery archive.

**Portfolio status:** course summary only. A future standalone C++ refactor would be a separately reviewed addition, not an import of the class archive.
