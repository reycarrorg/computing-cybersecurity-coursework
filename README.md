# Computing and Cybersecurity Coursework

This public repository is a curated portfolio of my computing and cybersecurity coursework. It contains selected student-authored projects and course summaries, not a complete academic archive or an answer bank. Some original assignments, classroom materials, and personal records are intentionally absent even when their subjects are described here.
